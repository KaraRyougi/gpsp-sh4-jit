What is this?

The fx-CG100 (SH-4A) is big-endian. The cgba host-order build stores guest memory pre-byteswapped so it reads the ROM with no per-access swap. A normal .gba is little-endian, so it must be converted (each 32-bit word reversed) before use with that build. The conversion is its own inverse — run it again to get the original back. Equivalent CLI: python3 tools/gba_hostswap.py in.gba out.gba.

cgba — GBA emulator port for the Casio fx-CG100.
